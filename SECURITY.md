# Security policy

## Supported versions

The latest release and the `edge` image (newest build from `main`) receive
security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately — do not open a public issue:

- GitHub: Security → [Report a vulnerability](https://github.com/briltago/printrio-software/security/advisories/new)
- E-mail: [support@printrio.app](mailto:support@printrio.app) with "Security" in the subject

Include the Printrio version (bottom of the sidebar), how to reproduce the problem
and its impact. We acknowledge reports within 3 working days and aim to release
a fix within 30 days, and we will credit you in the release notes unless you
prefer otherwise.

Klipper, Moonraker and slicers are separate projects; report their issues to
them.
